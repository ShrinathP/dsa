/*
Striver explanation and code
Problem Statement
Given are the two distinct words startWord and targetWord, and a list denoting wordList of unique words of equal lengths. 
Find the length of the shortest transformation sequence from startWord to targetWord.

In this problem statement, we need to keep the following conditions in mind:

- A word can only consist of lowercase characters.
- Only one letter can be changed in each transformation.
- Each transformed word must exist in the wordList including the targetWord.
- startWord may or may not be part of the wordList

beginWord = 'hit', endWord = 'cog'
wordList = [hot, dot, dog, lot, log, cog]
transformation = hit -> dot -> dog -> lot -> log -> cog
length = 3

https://takeuforward.org/graph/word-ladder-i-g-29/

================================================================================================================
Steps
1. BFS Traversal, Init Queue of Pair(word, steps) Pair will store the currentWord and transformation steps to reach that word, 
    - add startWord to queue, and 1 as length of sequence Path
    q.add(new Pair(startWord, 1))
2. Save all words to the hashset, remove startWord from hashset
3. BFS traversal - IMP, 
while !q.isEmpty(), poll from queue. get currentWord, get steps, 
    3.1 - base case - found targetWord
    if word == targetWord return steps
    3.2 - for every index i of the currentWord, replace with char from 'a' to 'z', check if match found in hashset
    if matchfound, add to queue with step + 1, remove from hashset
        - get charArray (IMP* why get charArray at each index ?)
        - for ch = 'a' to <= 'z'
            - replace i of the charArray
            charArray[i] = ch,
            - new word String replacedWord = new String(charArray);
            - if(hashset.contains(replacedWord)) {
                hashset.remove(replacedWord);
                q.add(new Pair(replacedWord, steps + 1));
            }
4. return 0, //no transformation sequence possible
================================================================================================================

Q: IMP* why get charArray at each index ?
For every position i, we are asking:
"What if only the i-th character changes, while all the other characters remain exactly as in the original word?"
That's why each i must start from the original "hit", by:
Creating a fresh char[] (word.toCharArray()) at each index

*/



import java.util.*;
import java.lang.*;
import java.io.*;

class Main {

    public static void main(String[] args) throws IOException {
        String startWord = "der", targetWord = "dfs";
        String[] wordList = {
            "des",
            "der",
            "dfr",
            "dgt",
            "dfs"
        };

        Solution obj = new Solution();
        int ans = obj.wordLadderLength(startWord, targetWord, wordList);

        System.out.print(ans);

        System.out.println();
    }
}

class Pair {
    String first;
    int second;
    Pair(String _first, int _second) {
        this.first = _first;
        this.second = _second;
    }
}

class Solution {
    public int wordLadderLength(String startWord, String targetWord, String[] wordList) {
        // Creating a queue ds of type {word,transitions to reach ‘word’}.
        Queue<Pair> q = new LinkedList<>();
 
        // BFS traversal with pushing values in queue 
        // when after a transformation, a word is found in wordList.
        q.add(new Pair(startWord, 1));

        // Push all values of wordList into a set
        // to make deletion from it easier and in less time complexity.
        Set<String> hashset = new HashSet<String>();
        int len = wordList.length;
        for (int i = 0; i < len; i++) {
            hashset.add(wordList[i]);
        }

        //remove the startWord from the set as it will be used in the queue
        hashset.remove(startWord);
        
        while (!q.isEmpty()) {
            String word = q.peek().first;
            int steps = q.peek().second;
            q.remove();
      
            // we return the steps as soon as
            // the first occurence of targetWord is found.
            if (word.equals(targetWord) == true) return steps;

            // Now, replace each character of ‘word’ with char
            // from a-z then check if ‘word’ exists in wordList.
            for (int i = 0; i < word.length(); i++) {
                char replacedCharArray[] = word.toCharArray();
                //change the ith char of the word, and check if set contains that word,
                //if it exists, remove from the set, add to the queue, so that it will be picked in next iteration
                //if not, move i ahead
                for (char ch = 'a'; ch <= 'z'; ch++) {
                    replacedCharArray[i] = ch;
                    String replacedWord = new String(replacedCharArray);

                    // check if it exists in the set and push it in the queue.
                    if (hashset.contains(replacedWord) == true) {
                        hashset.remove(replacedWord);
                        q.add(new Pair(replacedWord, steps + 1));
                    }
                }

            }
        }
        // If there is no transformation sequence possible
        return 0;
    }
}
